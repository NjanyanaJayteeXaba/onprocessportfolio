## 🚀 How to Enable GitHub Pages Hosting

Follow these simple steps to host your website for free on GitHub:

### Step 1: Enable GitHub Pages in Repository Settings

1. Go to your GitHub repository: `https://github.com/NjanyanaJayteeXaba/onprocessportfolio`
2. Click on **Settings** (top menu)
3. In the left sidebar, click on **Pages**
4. Under **Source**, select **GitHub Actions**
5. The workflow will automatically deploy your site when you push to the `main` branch

### Step 2: Configure Custom Domain (Optional)

If you want to use your custom domain (like `jayteexaba.tech`):

1. In the same **Pages** settings
2. Under **Custom domain**, enter: `jayteexaba.tech`
3. Click **Save**
4. Configure your domain's DNS settings (with your domain registrar):
   - Add an `A` record pointing to GitHub's IP addresses:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - OR add a `CNAME` record pointing to: `njanyanaJayteeXaba.github.io`

### Step 3: Wait for Deployment

- Once you push changes to the `main` branch, GitHub Actions will automatically deploy your site
- Check the **Actions** tab to see the deployment progress
- Your site will be live in a few minutes!
