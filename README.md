### 🔒 Security and API Architecture

Security is a massive priority for me. The live website is fully encrypted over HTTPS to protect all visitor data and ensure a safe browsing environment. 

I recently integrated an AI chatbot into the platform. When building the initial version, I kept the repository strictly private. I successfully configured the backend to handle user inputs and manage API requests through Netlify serverless functions. This ensured my private API keys stayed completely hidden from the client side. 

Before making this code public, I deliberately revoked those initial API keys as a standard security practice. Moving forward, I am planning to migrate the AI assistant to the Nvidia API to leverage their free tier models. This will allow the bot to run smoothly without the constant worry of billing limits or key leaks.
